# پروژه نهایی
برنامه مدیریت امور تحصیلی و نمرات دانشجویان دانشگاه

# توضیحات
- این برنامه فعلا مخصوص سیستم عامل ویندوز طراحی شده و در دیگر سیستم عامل ها ممکن است به درستی کار نکند.

- پروژه را حتما با کامپایلر `gcc` و در ویندوز کامپایل کنید و حتما فایل خروجی را خارج از `vscode` یا ادیتور ها و IDE های دیگر اجرا کنید

- می توانید از نسخه ریلیز هم استفاده کنید

# قوانین
- نام کاربری فقط میتواند شامل حروف کوچک انگلیسی، اعداد و آندرلاین (زیرخط، آندراسکور، _ ) باشد.

# قابلیت های ویژه
- ورودی رمزعبور با چاپ ستاره
- فیلتر کردن کاراکترهای همه ورودی‌ها
- لو ندادن نام کاربری و رمز درست حین لاگین کردن
- چاپ تمیز خروجی
- جدول های مرتب در بخش گزارش ها
- بکاپ گیری مناسب
- گزینه استفاده از بکاپ
- ثبت ورود کاربران
- قفل کردن نام کاربری بعد از تشخیص حمله بروت فورس
- قابلیت تغییر تم رنگی برنامه
- صدای ارور بعد از وارد کردن اطلاعات اشتباه در بخش لاگین
- کپچا
- نمایش جدول ورود موفق و ناموفق کاربران
- درهم کردن (هش کردن) مناسب رمزهای عبور و افزودن سالت
- پاک کردن تمام ردپاهای مربوط به رمزعبورهای اصلی در رم
- قبول نکردن رمزعبور های ساده هنگام تنظیم رمزعبور جدید
